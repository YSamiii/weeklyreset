# Weekly Reset 3.0

以可稳定部署的 iPad v23 为基础重构，保持原有 GitHub Pages 文件结构和本地数据格式。

## 3.0 界面

- 今日页使用视频封面与训练信息并列的大卡片。
- 周计划按日期、封面、内容和操作分区，按钮不再挤压标题。
- 视频库使用统一媒体卡片、固定筛选区和更清楚的打卡入口。
- iPad 横屏、竖屏和分屏均有独立布局。
- 设置、记录、弹窗和按钮采用统一视觉系统。

## 保留功能

- 上周回顾、本周计划、下周预览。
- 本周与下周视频均不重复。
- 生理期排除腹肌训练及臀桥／骨盆抬高动作。
- Community Centre 普拉提课和瑜伽课，可覆盖当天视频。
- 视频库直接打卡。
- 完整 JSON 导入与导出。
- iPad 跨日自动切回今天。
- 视频优先在 YouTube App 打开。

## 部署

文件结构与 v23 一致。解压后将根目录中的文件上传并覆盖 GitHub 仓库同名文件。不要上传 ZIP 本身。


## 3.2
视频库新增喜欢/不喜欢偏好控制与膝盖友好候选。喜欢会影响未来排课权重；不喜欢会从未来自动排课中排除，但不会自动改动已锁定计划。
